# Glossary of the interface (DESIGN.md 6, M19)

Every dictionary in this folder is translated **by this table**. A term that has a row here is written exactly as in its column,
in every string that uses it. English (`en.ts`) is the source. `{name}` placeholders and markup are never touched.

Tone: `ru` — «вы»; `kk` — «сіз»; `es` — «tú» (imperative); `fr` — «vous»; `pt` — «você» (Brazil); `de` — infinitive or noun forms, no direct
address where it can be avoided; `ja` — です・ます; `zh` — simplified, no pronouns; `hi` — «आप»; `ar` — Modern Standard Arabic.
Names of products and technologies stay as they are: Decka, Windows, USB, Wi-Fi, QR, OBS, Twitch, YouTube, Claude, Codex, Spotify, Discord.
