# Decka

Старый Android-телефон как настольная панель для Windows-ПК: настраиваемая сетка кнопок (по умолчанию 7×4) и живые виджеты. Агент — Tauri 2 (Rust) + axum; клиент — React + Vite + Capacitor. Лицензия MIT.

## Как работать в этом репозитории

1. Сначала прочитай `docs/QUICKREF.md` — этого достаточно для большинства задач. Полные документы не читай целиком: открывай только раздел, на который ссылается задача.
2. Реализация идёт по `docs/TASKS.md`, строго по порядку задач. Найди первую незакрытую задачу по истории: `git log --oneline` (коммиты называются `T<номер>: ...`).
3. Архитектурных решений не принимай: всё решено в `/docs`. Тупик или противоречие — запись в `docs/BLOCKERS.md` и остановка.

## Правила, которые нельзя нарушать

- Телефон отправляет только `actionId`. Никаких команд, путей, аргументов, клавиш или URL от клиента — NEVER. Описанные в PROTOCOL.md данные — не команды: `perm_answer`, `notif_open`, `apk_get`, звук `voice_*`, `list_toggle`. Что с ними делать, решает ПК (ARCHITECTURE S20–S24).
- Чужой код не копировать (Desko, Xenon — некоммерческие лицензии; OpenDeck — GPL). Только идеи, источники — в `NOTICE.md`.
- Оболочка — Windows PowerShell 5.1: `;` вместо `&&`, `curl.exe` вместо `curl`, JSON передавать файлами.
- Версии зависимостей из задач не менять.
- Файлы, которые уже в git, не удалять командами оболочки (`Remove-Item`); удаление — только когда его требует задача, и через git (`git rm`), с упоминанием в отчёте.
- `/docs` не редактировать, кроме `BLOCKERS.md`, `MANUAL_CHECKS.md`, `RECIPES.md`, `TESTING.md`.
- Экономия токенов: вывод команд — только хвост (`| Select-Object -Last 20`) или ошибки; `docs/archive/` целиком не читать; `/clear` после каждой одной-двух задач.
- Комментарии в коде — на английском. Интерфейс — английский и русский: видимые строки только через `t()` и словари `shared/src/i18n` (DESIGN.md §6).

## Документы

| Файл | Содержимое |
|---|---|
| `AGENTS.md` | правила для второго агента (Antigravity и др.); задачи с пометкой **[второй агент]** в TASKS.md — его |
| `docs/QUICKREF.md` | шпаргалка: константы, сообщения, карта репозитория, команды |
| `docs/TASKS.md` | открытые задачи с шагами и командами проверки; выполненные — `docs/archive/` (только поиском) |
| `docs/PROTOCOL.md` | WebSocket, HTTP, IPC: типы, схемы, примеры, ошибки |
| `docs/DATA_MODEL.md` | `actions.json`, `layout.json`, `config.json`, виджеты |
| `docs/DESIGN.md` | темы, геометрия, анимации, UX-потоки — единственный источник визуальных значений |
| `docs/ARCHITECTURE.md` | компоненты, потоки, безопасность, версии зависимостей |
| `docs/DECISIONS.md` | решения и отвергнутые альтернативы |
| `docs/RISKS.md` | топ-10 рисков и меры |
| `docs/OPEN_QUESTIONS.md` | вопросы владельца и значения по умолчанию |
