# DESIGN.md — визуальная система Decka (M13)

Решение владельца 2026-11-15: визуальная часть — главный приоритет продукта. Этот документ — единственный источник значений для тем, геометрии, анимаций и UX-потоков. Исполнитель не подбирает цвета и размеры на глаз: всё, чего здесь нет, — запись в `BLOCKERS.md`.

Правила для всех тем:
- Чужие фирменные ресурсы NEVER: никаких логотипов, иконок, шрифтов и названий Elgato, Apple, Google в интерфейсе. Темы — собственные интерпретации стилей.
- Одна геометрия для всех тем (§2): тема меняет только поверхности, цвета, тени, эффекты и анимации нажатия. Раскладка от смены темы не меняется.
- Защита AMOLED (M8) действует во всех темах: затемнение, заставка, pixel shift.
- Контраст подписей ≥ 4.5:1 к фону клавиши (WCAG AA) во всех темах; проверяется в T13.11.

## 1. Темы

`display.theme`: `"amoled" | "studio" | "material" | "glass"`. По умолчанию для новых установок — `"studio"`; отсутствие поля в существующем `layout.json` = `"amoled"` (у пользователя ничего не меняется без его выбора).

Темы реализуются как наборы CSS-переменных на корне клиента (`[data-theme="…"]`) плюс модификаторы компонентов. Названия в окне настроек: `AMOLED`, `Studio`, `Material`, `Glass`.

### 1.1 AMOLED — «чёрный экран, тонкая обводка»

| Токен | Значение |
|---|---|
| фон экрана | `#000000` |
| лицевая сторона клавиши | прозрачная |
| обводка | `1px solid rgba(255,255,255,0.16)`; цветная клавиша — `color` с непрозрачностью 0.5 |
| цветная клавиша | фон `color` с непрозрачностью 0.16, иконка `color` (тёмные цвета, яркость < 64 — иконка `#e5e5e5`) |
| иконка / подпись | `#e5e5e5` / `#9ca3af`, вес 500 |
| радиус | `0.22 × side` |
| тень, блик | нет |
| нажатие | фон `rgba(255,255,255,0.10)`, масштаб 0.94 |
| панели виджетов | без фона и обводки |

### 1.2 Studio — «аппаратная дека»

| Токен | Значение |
|---|---|
| фон экрана | `#000000` |
| лицевая сторона | `linear-gradient(180deg, #1c1c22, #0d0d10)` |
| цветная клавиша | `linear-gradient(180deg, mix(color, white 12%), mix(color, black 18%))`, иконка `#ffffff` |
| обводка | `1px solid rgba(255,255,255,0.10)` (цветная — 0.18) |

| иконка / подпись | `#f2f2f2` / `#ffffff`, вес 600, `text-shadow: 0 1px 2px rgba(0,0,0,0.9)` |
| радиус | `0.16 × side` |
| нажатие | масштаб 0.94, тень `inset 0 2px 6px rgba(0,0,0,0.8)`, `brightness(1.25)` |
| панели виджетов | та же лицевая сторона без цвета |

### 1.3 Material — по мотивам Material 3 (тёмная схема)

- Палитра генерируется из акцентного цвета `display.accent` (по умолчанию `#7c5cff`) библиотекой `@material/material-color-utilities` 0.4.0: `SchemeTonalSpot` (или эквивалент API этой версии), `isDark = true`, contrast 0. Используются роли: `surface`, `surfaceContainer`, `surfaceContainerHigh`, `onSurface`, `onSurfaceVariant`, `primary`, `primaryContainer`, `onPrimaryContainer`, `outlineVariant`.
- Фон экрана: **`#000000`** (решение владельца 2026-11-20: на AMOLED чёрные пиксели не светятся, а фон — самая большая площадь; было `surface`, серое на сером). Окно настроек и превью используют тот же чёрный. Клавиша: `surfaceContainerHigh`, иконка `onSurface`, подпись `onSurfaceVariant`, вес 500. Обводки и тени нет (тональная глубина вместо теней).
- Цветная клавиша: для её `color` генерируется своя схема (тот же алгоритм, seed = `color`, кэш по цвету); фон `primaryContainer`, иконка и подпись `onPrimaryContainer`.
- Радиус: `0.24 × side`; при нажатии радиус анимируется до `0.36 × side` (морфинг формы) и поверх — слой состояния `onSurface` с непрозрачностью 0.12; отпускание — обратно за 150 мс.
- Пульсация состояния `pending` — кольцо цвета `primary`.
- Панели виджетов: `surfaceContainer`, радиус `0.24 × side`.
- Шрифт: системный (`system-ui`; на Android это Roboto).

### 1.4 Glass — «жидкое стекло»

Цель — максимально близкое к системному стеклу Apple ощущение средствами WebView: размытие и насыщение фона, преломление по краям, зеркальный блик на кромке, лёгкая «упругость» при нажатии. Это интерпретация, не копия: системный материал Apple в WebView недоступен.

- Фон (обязателен — стеклу нужно что-то за собой): `display.wallpaper` (§1.5), по умолчанию `"aurora"`.
- Клавиша (слои снизу вверх):
  1. `backdrop-filter: blur(16px) saturate(180%)` + фон `rgba(255,255,255,0.07)`;
  2. преломление: SVG-фильтр `#decka-glass` (`feTurbulence` baseFrequency 0.008, numOctaves 2 → `feGaussianBlur` 2 → `feDisplacementMap` scale 26, каналы R/G), применённый как `backdrop-filter: url(#decka-glass) blur(16px) saturate(180%)` — **только если поддерживается** (проверка в T13.5); иначе слой пропускается;
  3. кромка: псевдоэлемент с рамкой 1px и маской-градиентом `linear-gradient(135deg, rgba(255,255,255,0.55), rgba(255,255,255,0.08) 40%, rgba(255,255,255,0.0) 60%, rgba(255,255,255,0.25))`;
  4. внутренний блик: `inset 0 1px 1px rgba(255,255,255,0.45), inset 0 -1px 1px rgba(255,255,255,0.08)`;
  5. тень: `0 6px 18px rgba(0,0,0,0.35)`.
- Цветная клавиша: дополнительный слой `color` с непрозрачностью 0.32 под бликом.
- Иконка `#ffffff` с `drop-shadow(0 1px 2px rgba(0,0,0,0.35))`; подпись `#ffffff`, вес 600, та же тень.
- Радиус `0.26 × side`.
- Нажатие: масштаб 0.92 с «пружиной» (`cubic-bezier(0.34, 1.56, 0.64, 1)`, 260 мс на отпускание), блик ярче (`inset 0 1px 2px rgba(255,255,255,0.75)`), световое пятно из точки касания (радиальный градиент `rgba(255,255,255,0.25)`, гаснет за 300 мс).
- Панели виджетов — то же стекло, радиус `0.26 × side`.
- Производительность: при старте темы клиент 3 с меряет частоту кадров (`requestAnimationFrame`); средняя < 45 к/с → режим `reduced` (решение D-2, уточнено 2026-11-15: **без `backdrop-filter`, но с «матовым стеклом» из заранее размытого фона**. Вместе с «фоном 1» (§1.5) клиент готовит «фон 2» — тот же canvas, размытый сильнее (`blur(6px)` поверх уже размытого «фона 1», то есть ≈ 72 px на полном экране) и осветлённый `saturate(160%)`. Каждая клавиша и панель виджета получает «фон 2» как `background-image` с `background-size` = размер экрана и `background-position` = `-left -top` клавиши относительно экрана — так под стеклом виден «размытый кусок обоев» точно в её месте; поверх — тон `rgba(255,255,255,0.08)`, кромка, блик и тень как в обычном режиме. Позиции пересчитываются только при изменении сетки или размера экрана. Анимация смещения обоев в `reduced` выключена, поэтому совмещение не съезжает. Цветная клавиша — дополнительно слой цвета 0.32, как обычно), сохраняется в `localStorage` ключом `decka.glass.reduced.v1`. Переключатель `Reduce effects` в меню телефона (§4.3) принудительно включает/выключает режим.

### 1.5 Обои (только тема Glass)

`display.wallpaper`: `"aurora" | "sunset" | "ocean" | "graphite" | "album"`.

| id | Определение (CSS, фон `#05060a`) |
|---|---|
| `aurora` | `radial-gradient(60% 80% at 15% 20%, #6d28d9 0%, transparent 60%), radial-gradient(50% 70% at 85% 30%, #0ea5e9 0%, transparent 60%), radial-gradient(70% 60% at 50% 100%, #10b981 0%, transparent 65%)` |
| `sunset` | `radial-gradient(60% 80% at 20% 30%, #f97316, transparent 60%), radial-gradient(60% 80% at 80% 20%, #db2777, transparent 60%), radial-gradient(80% 60% at 50% 100%, #7c3aed, transparent 65%)` |
| `ocean` | `radial-gradient(60% 80% at 20% 20%, #1d4ed8, transparent 60%), radial-gradient(60% 70% at 80% 60%, #0891b2, transparent 60%), radial-gradient(70% 60% at 40% 100%, #0f766e, transparent 65%)` |
| `graphite` | `radial-gradient(70% 90% at 30% 20%, #3f3f46, transparent 60%), radial-gradient(60% 80% at 80% 80%, #27272a, transparent 60%)` |
| `album` | обложка текущего трека (`media.art`), `filter: blur(48px) brightness(0.55) saturate(140%)`, масштаб 1.3; без обложки — `aurora` |

Затемнение (решение D-1, 2026-11-15): поверх обоев `aurora`/`sunset`/`ocean`/`graphite` лежит сплошной слой `rgba(0,0,0,0.35)` (под клавишами, над градиентом). У `album` своё затемнение (`brightness(0.55)`), слой не добавляется. Расчёт: худший участок `#10b981` → белая подпись 4.8:1, `#0ea5e9` → 5.1:1, `#f97316` → 5.2:1.

Защита от выгорания: слой обоев смещается по кругу радиусом 3% (`transform: translate`) **ступенями**: новая точка каждые 30 с, переход 2 с (решение D-2: непрерывное движение фона заставляло каждый кадр заново размывать фон под всеми клавишами). **Заранее размытый фон (уточнение 2026-11-15: растянутая картинка 24×24 давала пятна и ступени вместо размытия — отменено).** Обои любого типа (`album` и градиенты) клиент один раз рисует в `canvas` размером ¼ экрана (A57 ≈ 585×257): градиент — тем же CSS-определением через `createRadialGradient`, обложку — `drawImage` с масштабом 1.3 и `ctx.filter = "blur(12px) brightness(0.55) saturate(140%)"` (в ¼ разрешения это соответствует ≈ 48 px на полном экране); поверх — затемнение §1.5 и шум против полос: случайные пиксели ±3 по яркости (`ImageData`, один проход). Результат — `canvas.toBlob` → object URL → фон слоя обоев, растянутый со сглаживанием: исходник уже гладкий, артефактов нет. Перерисовка — только при смене обоев, обложки (`media.art`) или размера экрана. Это «фон 1» (обои); в режиме `dim` обои затемняются вместе со всем экраном; заставка (`sleep`) — чёрная, без обоев.

### 1.6 Читаемость цветных клавиш (все темы)

Подпись и иконка на цветной клавише по умолчанию белые. Если белая подпись даёт контраст < 4.5 с итоговым цветом клавиши, клиент затемняет цвет клавиши (в пространстве OKLCH или HSL — по уже реализованной `readableFace`) ровно до 4.5.

Исключение для светлых цветов (уточнение 2026-11-15: белая клавиша превращалась в `#606060`): если подпись `#0b0b0f` даёт с исходным цветом контраст ≥ 7, цвет не затемняется, а подпись и иконка становятся `#0b0b0f` (без тени). Так белая, жёлтая и светло-зелёная клавиши остаются такими, какими их выбрал владелец, а средние тона (например `#7c5cff`, где тёмная подпись даёт < 7) затемняются под белую подпись. Цвет, сохранённый в `layout.json`, не меняется — затемняется только отображение. Редактор на ПК показывает клавишу так же, как телефон.

Контраст ≥ 4.5 обязателен для всего текста на клавишах и в виджетах, включая второстепенный (подзаголовки виджетов, «+2 more», время уведомлений). Исключения — только неактивные элементы и индикатор страниц.

## 2. Геометрия (общая)

Функция `gridMetrics(viewport, cols, rows)` — как в archive/TASKS-M0-M13.md, T11.10 «Итоговая спецификация» п. 1: квадратные клавиши со стороной `side`, зазор `max(4, round(0.04 × side0))`, сетка центрирована.

| Элемент | Значение |
|---|---|
| иконка `lucide:`/`emoji:`/`img:` svg | `round(0.46 × side)`; со смещением вверх `0.07 × side`, если есть подпись |
| иконка `img:` png | `round(0.62 × side)`, скругление `0.10 × side`; при наличии подписи — `0.52 × side` |
| подпись | внутри клавиши снизу, отступ `0.07 × side`, `max(11px, 0.14 × side)`, одна строка с многоточием; без иконки — по центру, `0.19 × side`, до двух строк |
| шеврон `navigate` | `›` в правом верхнем углу, `0.14 × side`, непрозрачность 0.5 |
| значок `popup` | три точки `•••` в правом верхнем углу, `0.12 × side`, непрозрачность 0.5 |
| панель виджета | внутренний отступ `0.08 × side` |

### 2.1 Режим «Большая иконка» (решение владельца 2026-11-15)

Иконка заполняет клавишу без отступов, как иконка приложения на домашнем экране; подпись по желанию лежит поверх. Включается для всех кнопок (`display.keyFace`, вкладка `Look`) или для одной кнопки (`face`, переключатель в панели свойств и флажок `Big icon` в контекстном меню). Подпись: `display.keyLabels` и `showLabel` у кнопки (DATA_MODEL.md §3).

| Иконка | Как рисуется в режиме `full` |
|---|---|
| `img:` png с непрозрачными углами (клиент один раз на hash проверяет альфу четырёх угловых пикселей через `canvas`, ≥ 250 → «плитка») | `object-fit: cover` на всю клавишу, обрезка по радиусу клавиши; фон клавиши не виден |
| `img:` png с прозрачностью (обычные иконки программ Windows) | `object-fit: contain`, `round(0.84 × side)`, по центру; под ней фон клавиши (цвет кнопки или поверхность темы) |
| `lucide:`, `img:` svg (Phosphor), `emoji:` | `round(0.68 × side)` по центру (векторный знак во всю клавишу выглядит грубо) |

- **Подпись поверх** (если показывается): снизу, на градиенте `linear-gradient(to top, rgba(0,0,0,0.78) 0%, rgba(0,0,0,0.6) 32%, rgba(0,0,0,0) 62%)` во всю ширину (уточнение 2026-11-15: при прежнем градиенте у верхнего края подписи белый текст на белой картинке давал 3.3:1; теперь вся строка подписи лежит на слое ≥ 0.6 → ≥ 5.7:1); текст `#ffffff`, вес 600, `max(11px, 0.13 × side)`, тень `0 1px 2px rgba(0,0,0,0.6)`, одна строка с многоточием, отступы `0.08 × side` по бокам и снизу. Правило §1.6 (тёмная подпись) в режиме `full` не применяется: подпись всегда на тёмном градиенте. Проверка контраста — белый текст против `#ffffff` под градиентом с непрозрачностью, вычисленной **на уровне верхнего края строки подписи** (`0.08 × side` + высота строки от низа клавиши) → ≥ 4.5.
- **Слои темы поверх картинки:** обводка AMOLED и Studio, кромка и блик Glass, состояние нажатия (масштаб, подсветка) рисуются над иконкой; `backdrop-filter` Glass под непрозрачной «плиткой» не включается (экономия кадров).
- Шеврон `navigate` и значок `popup` — в правом верхнем углу на кружке `rgba(0,0,0,0.45)` диаметром `0.2 × side`.
- **Чёткость:** иконки программ хранятся 256×256 (DATA_MODEL.md §8.1). Старые иконки 96×96 работают, но в режиме `full` размыты: окно настроек показывает в `Look` строку `Some app icons are low-resolution — Sharpen` (команда `refresh_program_icons`), если такие есть.

### 2.2 Книжная ориентация (M14, DATA_MODEL.md §3.7)

- `gridMetrics` не меняется: она уже вписывает квадратные клавиши в любое окно. В книжной ориентации по умолчанию 4×7 (из 7×4), сторона клавиши на S9 ≈ 80 CSS-px, на A57 ≈ 95.
- Системные полосы скрыты так же, как в альбомной; отступ сетки снизу дополнительно учитывает `env(safe-area-inset-bottom)` (жестовая полоса Android).
- Индикатор страниц — внизу по центру, как в альбомной; свайп между страницами — горизонтальный (не меняется).
- Меню телефона (§4.3) — нижний лист на всю ширину; всплывающая группа (§4.1) — та же `placePopup`, панель по-прежнему над нажатой клавишей, а если сверху не помещается — под ней.
- Виджет `media` при `w ≤ 2` в книжной сетке: обложка сверху, текст под ней, при `h ≥ 2`; правило клавиш §6.2 DATA_MODEL не меняется.
- Заставка, затемнение и сдвиг пикселей работают одинаково в обеих ориентациях.
- Окно настроек: рамка телефона в превью редактора и в карточках тем поворачивается по `display.orientation`; редактор занимает ту же область, превью вписывается по высоте.
- До сопряжения (нет раскладки) приложение использует последнюю известную ориентацию из `localStorage` `decka.orientation.v1`, иначе альбомную.

### 2.4 Кнопки с состоянием и цвета пресетов (M15)

Один язык состояний для всех готовых кнопок (каталог DATA_MODEL.md §9) — состояние никогда не передаётся только цветом:

| Состояние | Вид |
|---|---|
| обычное / выключено | цвет кнопки по умолчанию темы, обычная иконка |
| **тревожное активное** — микрофон выключен, идёт запись, эфир | заливка `#dc2626`, иконка сменяется (`mic-off`, точка записи), подпись меняется (`Mic off`, `REC`, `LIVE`); у записи и эфира — красная точка `0.12 × side` в левом верхнем углу, мигает раз в секунду (`reduced` / `prefers-reduced-motion` — не мигает) |
| **включённый режим** — shuffle, repeat, текущая сцена OBS | заливка акцентом (`display.accent`), иконка та же |
| нет данных (переменной нет: OBS не подключён, нет микрофона) | непрозрачность 0.45, нажатие работает и показывает ошибку как обычно. **Только для зарезервированных переменных** `audio.*`, `mic.*`, `media.*`, `obs.*` (уточнение 2026-11-16): пользовательская переменная, которой ещё нет, означает обычное состояние, кнопка не тускнеет. В превью редактора кнопки не тускнеют никогда |

- Цвета пресетов: системные и медиа — без цвета (нейтральные); `Lock`, `Sleep` — `#b91c1c`; сервисные (OBS) — без собственного цвета, состояние даёт цвет. Контраст подписи — правило §1.6 (`readableFace`), применяется и к цветам состояний.
- Подписи пресетов ≤ 10 символов на обоих языках, чтобы помещаться в клавишу 80 px.

## 3. Движение

| Событие | Анимация |
|---|---|
| смена страницы свайпом | страница следует за пальцем; отпускание — доводка за 220 мс `cubic-bezier(0.2, 0.8, 0.2, 1)`; порог — 25% ширины или скорость > 0.5 px/мс |
| смена страницы кнопкой / контекстом | сдвиг 220 мс в сторону направления |
| нажатие клавиши | по теме (§1); вход 80 мс, выход 150 мс (Glass — пружина 260 мс) |
| открытие всплывающей группы (§4.1) | затемнение фона 160 мс; панель из точки нажатой клавиши: `scale 0.85 → 1`, `opacity 0 → 1`, 200 мс, пружина; закрытие — обратное, 140 мс |
| тост | сверху: `translateY(-8px) → 0`, `opacity`, 180 мс |
| `prefers-reduced-motion` или режим `reduced` | все переходы ≤ 100 мс без масштабирования, пружины заменяются на `ease-out` |

## 3a. Виброотклик (решение владельца 2026-11-15)

Реализация: в приложении — `@capacitor/haptics` 8.0.2; в браузере — `navigator.vibrate(ms)` (где есть; в незащищённом контексте и на iOS-браузерах отсутствует — молча пропускать). Все вызовы — через один модуль `client/src/platform/haptics.ts` (`haptic(kind)`), ошибки глотаются.

| Событие | `kind` | Capacitor | Браузер (`vibrate`) |
|---|---|---|---|
| касание клавиши (`pointerdown` на кнопке, ключе виджета, клавише панели группы) | `tap` | `impact({ style: Light })` | 10 мс |
| завершение удержания `confirm` (800 мс) — в момент отправки | `confirm` | `impact({ style: Medium })` | 20 мс |
| ответ `press_result` с ошибкой (или таймаут) | `error` | `notification({ type: Error })` | `[30, 60, 30]` |
| открытие всплывающей группы | `open` | `impact({ style: Light })` | 10 мс |
| смена страницы (свайп, кнопка, контекст) | `page` | `selectionChanged()` (между `selectionStart`/`selectionEnd`) | 5 мс |
| долгое нажатие открыло меню телефона | `menu` | `impact({ style: Medium })` | 20 мс |

- Успешный `press_result` вибрацией не сопровождается (касание уже дало отклик; двойной отклик раздражает).
- Касание, которое только будит экран из `dim`/`sleep`, не вибрирует.
- Контекстная смена страницы, произошедшая без участия пользователя, не вибрирует (только ручная).
- Настройка на устройстве: переключатель `Haptics` в меню телефона (§4.3), по умолчанию включён; хранится в `localStorage` ключом `decka.haptics.v1` (try/catch). Глобальной настройки на ПК нет: это свойство конкретного телефона.
- Чистая функция `hapticFor(event, ctx) → kind | null` (учитывает правила выше и настройку) — с юнит-тестами.

## 4. UX-потоки

### 4.1 Всплывающие группы — релевантные кнопки по нажатию

Нажатие клавиши показывает поверх текущей страницы панель связанных кнопок (как раскрывающиеся группы на сенсорной панели ноутбука и папки на аппаратных деках).

- Источник кнопок — страница с `popup: true` (DATA_MODEL.md §3.1). Такие страницы не участвуют в свайпе, не показываются точками, не могут иметь `apps` и не могут быть первой страницей.
- Кнопка с `popup: <pageId>` открывает панель. Вариант «запустить и показать»: `actionId` + `popup` — сначала `press(actionId)`, после `ok` открывается панель (например, «VS Code»: запустить/активировать и сразу показать его команды). При ошибке действия панель не открывается.
- Панель: элементы popup-страницы раскладываются по своей ограничивающей рамке (`min x…max x+w`, `min y…max y+h`) с той же `side` и зазором; поверхность панели — панель виджета текущей темы с отступом `0.12 × side`; позиция — по центру над нажатой клавишей, сдвинута так, чтобы целиком помещаться на экране с отступом `pad`.
- Фон под панелью затемняется `rgba(0,0,0,0.55)` (Glass — плюс `backdrop-filter: blur(6px)`).
- Закрытие: тап вне панели; через 250 мс после успешного нажатия кнопки внутри панели, если у popup-страницы не задано `stayOpen: true`; через 10 с без касаний; жестом свайпа вниз по панели.
- Вложенность запрещена: кнопка с `popup` на popup-странице — ошибка валидации.

### 4.2 Контекстные страницы (M11) и группы вместе

Контекстная страница (по активному приложению) меняет всю страницу; группа — временная панель по нажатию. Открытая группа закрывается при автоматической смене страницы.

### 4.3 Меню телефона

Долгое нажатие 1,2 с на пустом месте страницы или на точках страниц (с круговым индикатором удержания) открывает нижний лист:
- строка состояния: `Connected to <PC> · USB` / `· Wi-Fi` / `Offline`;
- `Reduce effects` (переключатель, влияет на Glass и анимации);
- `Haptics` (переключатель виброотклика, §3a);
- M17: `Turn` — `Auto` / `Normal` / `Upside down` (DATA_MODEL.md §10.9); `App strips` — приложения со скрытой полосой, `Show again` (§4.10);
- `Reload`;
- `Unpair` (с подтверждением);
- версия приложения.
Скрытый жест «5 тапов в углу» удаляется (заменён меню).

### 4.4 Окно настроек

- **Мастер первого запуска** (если `devices.json` пуст и раскладка не менялась): 1) `Pair your phone` — крупный QR и код; 2) `Pick a look` — четыре карточки тем с живым превью; 3) `Add your apps` — список установленных программ (M12) с флажками: выбранные становятся действиями и кнопками на первой странице в свободных клетках; кнопки `Back` / `Next` / `Skip`.
- **Редактор раскладки «что видишь — то и получишь»**: в центре — настоящий рендер деки в выбранной теме (общие компоненты `@decka/ui`, DECISIONS.md D-37) в рамке условного телефона в альбомной ориентации; клик по клавише — панель свойств справа; перетаскивание клавиши — перемещение на пустую клетку или обмен с занятой; перетаскивание из левой палитры (вкладки `Apps`, `Actions`, `Widgets`) на клетку — создание; угловая ручка у виджета — изменение размера; `Ctrl+Z`/`Ctrl+Y` — отмена/повтор (50 шагов); `Ctrl+S` — сохранить; метка `Unsaved changes`.
- **Уточнение M14 (отзыв владельца 2026-11-15: «создание кнопки слишком сложное, не могу перетащить, нет онбординга»)** — §4.5–§4.7 имеют приоритет над этим пунктом.
- **Вкладка `Appearance`**: тема (4 карточки с превью), акцент (для Material; 8 готовых цветов + произвольный), обои (для Glass), переключатель контекстных страниц, параметры экрана (перенос блока `Display` из Layout).
- Внешний вид окна: системный шрифт `Segoe UI Variable` / `system-ui`; сетка отступов 8 px; боковое меню с иконками Phosphor (regular, 20 px); светлая и тёмная тема окна по системной; акцент окна = `display.accent`.

### 4.5 Кнопка за два клика (M14)

Цель: любая программа или частое действие ставится на клетку двумя кликами, без форм.

- **Пустая клетка** в превью при наведении показывает `+` (иконка Phosphor `plus`, цвет — приглушённый текст темы окна). Клик → **быстрый выбор** — всплывающее окно у клетки шириной 360 px:
  - поле поиска в фокусе (`Search apps and actions…`), стрелки и `Enter` работают, `Esc` закрывает;
  - группы сверху вниз: `Apps` (установленные программы M12, с иконками, сортировка по имени; при поиске — по совпадению), `Media & system` (готовые действия, таблица ниже), `Your actions` (уже существующие в `actions.json`), `Widgets` (виджеты, которые помещаются в клетку с её позиции);
  - нижняя строка: `Browse for a program…` (системный диалог `.exe`/`.lnk` → `describe_program`), `Website…` (поле URL), `Keyboard shortcut…` (запись сочетания: «Press the keys», показывает сочетание, `Enter` — готово).
  - Клик по пункту → кнопка создана **сразу**: имя, иконка и действие заполнены автоматически, клавиша выделена, справа открыта панель свойств. Больше ничего делать не нужно.
- **Готовые действия** `Media & system`:

| Пункт | Действие | Иконка |
|---|---|---|
| Play / Pause | media `play_pause` | `lucide:play` |
| Next track | media `next` | `lucide:skip-forward` |
| Previous track | media `prev` | `lucide:skip-back` |
| Volume up | media `vol_up` | `lucide:volume-2` |
| Volume down | media `vol_down` | `lucide:volume-1` |
| Mute | media `mute` | `lucide:volume-x` |
| Lock PC | system `lock`, `confirm: true` | `lucide:lock` |
| Sleep | system `sleep`, `confirm: true` | `lucide:moon` |

- **Правила создания:** программа → действие `launch` (program, args, cwd из ярлыка), иконка — `icon_from_program` (ошибка → `lucide:rocket`), подпись — имя программы (обрезка до 24 символов). Если в `actions.json` уже есть действие с тем же содержимым — переиспользуется. Id действия — slug имени (`[a-z0-9-]`, ≤ 48 символов) с суффиксом `-2`, `-3`… при совпадении. Сайт → `open_url`, иконка `lucide:globe`, подпись — домен без `www.`. Сочетание → `hotkey`, иконка `lucide:zap`, подпись — сочетание (`Ctrl+Shift+M`).
- **Перетаскивание из Проводника:** `.exe` или `.lnk`, брошенный на клетку превью, создаёт кнопку программы по тем же правилам; на занятую клетку — в ближайшую свободную, на полную страницу — сообщение `No free cell on this page`.
- **Палитра слева** остаётся (перетаскивание пунктов на клетку), но это второй путь, а не основной.

### 4.6 Правка и сохранение (M14)

- **Автосохранение:** каждое изменение раскладки или действий сохраняется через 600 мс после последней правки и сразу появляется на телефоне. Метка `Unsaved changes` и обязательный `Ctrl+S` убираются; вместо них в углу превью — `Saved` (гаснет за 1,5 с) или ошибка проверки у поля. Невалидное состояние формы не сохраняется. `Ctrl+Z`/`Ctrl+Y` остаются (50 шагов) и тоже сохраняются автоматически.
- **Перетаскивание клавиш** — на pointer-событиях (D-38): клавиша поднимается (масштаб 1.05, тень), клетка под курсором подсвечивается акцентом, занятая клетка показывает обмен (клавиша-сосед смещается в исходную клетку с анимацией 150 мс). Порог начала — 4 px; клик без движения = выбор.
- **Контекстные меню** (уточнение 2026-11-15: владелец сообщил, что правый клик не работает; второстепенное переносится сюда из панели свойств). Стандартное меню WebView2 (`Back`, `Refresh`, `Inspect`) подавляется во всём окне (`contextmenu` → `preventDefault`), кроме текстовых полей. Меню — собственный компонент: открывается у курсора, сдвигается внутрь окна, закрывается по `Esc`, клику вне и выбору пункта; стрелки и `Enter` работают; у пунктов — иконка Phosphor и подсказка сочетания справа.
  - **Клавиша-кнопка:** `Change action…` · `Change icon…` · `Rename` (`F2`, правка подписи прямо на клавише) · разделитель · `Big icon` (флажок, §2.1) · `Show name` (флажок) · `Color` (подменю: 8 образцов + `Custom…` + `Default`) · `Ask before running` (флажок) · разделитель · `Test on PC` · `Duplicate` (`Ctrl+D`) · `Make popup group` / `Edit popup group` · `Refresh app icon` (только для кнопок программ) · разделитель · `Delete` (`Del`).
  - **Виджет:** `Settings…` · `Size` (подменю допустимых размеров) · `Duplicate` · `Delete`.
  - **Пустая клетка:** `Add button…` (тот же быстрый выбор) · `Add widget` (подменю) · `Paste` (если в буфере окна есть клавиша; `Ctrl+C`/`Ctrl+V` копируют клавиши внутри окна).
  - **Вкладка страницы** (над превью): `Rename` · `Show automatically for apps…` · `Move left` / `Move right` · `Duplicate` · `Delete`.
  - Клавиша `Delete` удаляет выделенную клавишу (с возможностью `Ctrl+Z`; подтверждения нет).
- **Панель свойств** кнопки — только главное, сверху вниз: крупное превью клавиши; `Name` (подпись); `Icon` (клик → средство выбора, §5) и рядом переключатель-пара `Standard | Big icon`; строка «Does: <краткое описание действия>» с кнопкой `Change`. Всё прочее (цвет, подтверждение, дублирование, группы, обновление иконки) — в контекстном меню и в свёрнутом `More options` внизу панели (там же `bind`, числовые X/Y/W/H, `actionId + popup`). Пустая панель (ничего не выделено) показывает подсказку `Select a key, or click an empty cell to add one`.

### 4.6a Упрощение окна настроек (отзыв владельца 2026-11-15: «некоторые меню сложные для восприятия»)

Принципы: на экране только то, что нужно в 90% случаев; технические поля — в свёрнутом `More options`; вместо чисел и единиц — понятные варианты; ID никогда не вводятся руками; одна мысль — одна строка подсказки.

**Боковое меню: 4 пункта вместо 7.**

| Пункт | Что внутри | Откуда |
|---|---|---|
| `Deck` | редактор (превью, вкладки страниц, палитра, панель свойств) | Layout + создание действий |
| `Look` | тема, акцент, обои, стиль клавиш (`Standard` / `Big icon`, `Show names`), экран | Appearance |
| `Phone` | состояние связи и сопряжение на одной странице | Status + Pairing |
| `More` | `Actions`, `Integrations`, `Settings`, `About` — подразделы списком слева внутри страницы | Actions, Integrations, Settings |

Окно открывается на `Deck`; при `is_first_run` — мастер.

**Deck.**
- Сетка: вместо двух полей `Columns`/`Rows` — кнопка `Grid 7 × 4` над превью; клик → выбор размера наведением по мини-сетке 8×5 (как выбор размера таблицы в текстовом редакторе), подпись `7 × 4 · 28 keys`. Если уменьшение сетки выталкивает клавиши — диалог `3 keys don't fit. Move them to a new page?` с кнопками `Move` / `Cancel`.
- Страницы — вкладки над превью с `+` в конце; переименование двойным кликом; остальное — контекстное меню вкладки (§4.6). Стрелки `←`/`→` и кнопки страниц вне вкладок убираются.
- Кнопки `Undo`/`Redo` — иконки в углу превью рядом с меткой `Saved`.
- Форма `New item at x,y` удаляется (её заменяет быстрый выбор §4.5).

**Форма действия** (`More → Actions` и `Change action…`):
- `ID` скрыт и генерируется (`makeActionId`); тип — сегменты с иконками: `App` · `Website` · `Shortcut` · `Media` · `System`.
- `App`: строка с иконкой и именем выбранной программы и кнопкой `Choose…` (быстрый выбор, только группа `Apps` + `Browse`); `.lnk` принимаются (через `describe_program`). Аргументы и рабочая папка — в `More options`.
- `Shortcut`: поле записи сочетания (`Click and press keys`), без ручного ввода `ctrl+shift+m`.
- `Media`/`System`: сетка крупных плиток с иконкой и именем (`Play / Pause`, `Next`, … `Lock`, `Sleep`) вместо выпадающего списка.
- `Toggle variable` — в `More options`, с подписью `Switch a state after running (for buttons that show on/off)`.

**Look.**
- `Screen` — один выбор вместо пяти чисел: `Screen saving` = `Off` · `Balanced` (затемнить через 1 мин до 30%, заставка через 10 мин — совпадает со значениями по умолчанию) · `Maximum` (через 30 с до 15%, заставка через 3 мин) · `Custom` (раскрывает прежние поля, подписанные в минутах: `Dim after, min`, `Brightness when dimmed, %`, `Screen saver after, min`; в `layout.json` по-прежнему секунды и доли). Выбранный вариант определяется по значениям; несовпадение = `Custom`. По умолчанию `Balanced`.
- Ночной режим: флажок `Darker at night` + два поля `<input type="time">`.
- Акцент показывается только для тем, где он влияет на вид; обои — только для Glass (как сейчас).

**Phone.**
- Сверху — одна крупная карточка состояния: `Connected · Galaxy A57 · USB` (зелёная точка) / `Waiting for your phone` / `Server stopped — Restart`. Под ней — `Pair a new phone` (QR и код раскрываются по нажатию) и список телефонов с `Forget` вместо `Revoke`.
- Адреса, порт, путь к папке конфигурации — в `More options`. Предупреждение брандмауэра показывается только при проблеме (сервер слушает, а за 2 мин после сопряжения нет ни одного подключения по Wi-Fi).

**More → Integrations.**
- Таблица HTTP-проверок из 7 столбцов заменяется списком строк `● Name — url` с кнопкой `Add check` (состояние up/down в окне не показывается: у окна нет этих данных, точка нейтральная — принято 2026-11-15); диалог проверки — `Name` и `URL`; интервал, таймаут, ожидаемый код и группа — в `More options` (значения по умолчанию из DATA_MODEL.md).
- API-токен и примеры команд — без изменений, но примеры свёрнуты под `Show examples`.

**More → Settings.**
- Видно: `PC name`, `Start with Windows`, `USB connection` (флажок; путь `adb` ищется автоматически — поле показывается, только если не найден). `Port` и интервалы — в `More options`.

**Тексты:** кнопки — глаголом (`Add`, `Forget`, `Choose…`), без внутренних терминов (`actionId`, `navigate`, `popup page` → `action`, `Open page`, `popup group`); у полей — подсказки только там, где без них нельзя.

### 4.9 Выбор сочетания клавиш (M17, DATA_MODEL.md §10.3)

Поле `Click and press keys` остаётся сверху. ### 4.10 Полоса приложения на телефоне (M17, DATA_MODEL.md §10.5)

- **Место:** в альбомной ориентации — у правого края, ширина `2 × side + gap + 2 × pad`, вся высота области страниц. В книжной — снизу, высота `2 × side + gap + 2 × pad`. Поверхность и тень — как у панели всплывающей группы (§4.1), затемнения фона нет.
- **Заголовок 28 px:** иконка программы (`img:` из `icons`, иначе `lucide:app-window`), `name` и кнопка `⋯` справа.
- **Кнопки:** обычные клавиши текущей темы размера `side`, в 2 колонки (в книжной — 2 ряда) с прокруткой по длинной стороне.
- **Появление:** выезд от края 220 мс, кривая свайпа (§3). Сворачивание — в язычок: 20 × 56 px у края по центру, иконка программы 16 px, скругление со стороны экрана. Свайп полосы к краю тоже сворачивает её.
- **Совместимость:** полоса закрывает часть страницы, но не сдвигает её. Свайп страниц под полосой не работает, вне её — работает. Всплывающая группа открывается поверх полосы. При `reduced` — без тени и анимаций дольше 100 мс.
- **Меню `⋯`:** нижний лист как меню телефона, три варианта с отметкой текущего.

### 4.8a Панель библиотеки — вид и удобство (отзыв владельца 2026-11-20)

Найденные ошибки (снимок владельца, русский интерфейс): вкладки не помещаются — `Программы` обрезана справа (`.library .row.wrap { flex-wrap: nowrap }` при кнопках произвольной ширины); видна системная полоса прокрутки со стрелками; первый элемент списка частично скрыт под вкладками.

- **Шапка панели** (поиск и вкладки) не прокручивается: список прокручивается под ней. Отступы панели 12 px, между блоками 8 px.
- **Поиск:**
  - высота 36 px, радиус 10 px, лупа слева (Phosphor `magnifying-glass`, 16 px, `--muted`);
  - крестик очистки справа, только при непустом поле; `Esc` очищает;
  - подсказка в поле короче: `Search` / `Поиск`;
  - при фокусе — обводка акцентом 1.5 px.
- **Вкладки → сегментный переключатель на всю ширину:**
  - дорожка: `display: grid; grid-template-columns: repeat(3, minmax(0, 1fr))`, фон `--bg`, обводка `--border`, радиус 10 px, внутренний отступ 3 px;
  - сегмент: высота 30 px, радиус 7 px, шрифт 13 px / 500, `min-width: 0`, текст с многоточием;
  - активный сегмент — фон акцента, белый текст; переход фона 150 мс.
  - Подписи: `Keys` / `Sets` / `Apps`, по-русски `Кнопки` / `Наборы` / `Программы`. «Библиотека» внутри панели «Библиотека» лишняя.
- **Список:**
  - тонкая полоса прокрутки во всём окне: `scrollbar-width: thin; scrollbar-color: var(--border) transparent`, для WebView2 — `::-webkit-scrollbar` 8 px, бегунок с радиусом 4 px, кнопки-стрелки скрыты;
  - сверху у списка отступ 4 px, чтобы ничего не уходило под шапку.
- **Строка элемента:**
  - высота 36 px, радиус 8 px, без рамки, при наведении фон `--bg`;
  - слева иконка 20 px, затем имя (многоточие), подсказка справа мелко `--muted` (до 40% ширины);
  - при наведении справа — кнопка `+` 24 px: добавляет элемент в первую свободную клетку текущей страницы, как сброс туда. Это альтернатива перетаскиванию; нет места — тост `No free cell on this page`.
  - Перетаскивание остаётся.
- **Категории:**
  - заголовок 32 px; при прокрутке закрепляется внутри списка (`position: sticky`, фон панели);
  - число элементов справа мелко;
  - открыта первая категория, остальные свёрнуты; при поиске — плоский список с совпадением, выделенным жирным.
- **Клавиатура:** `↓` из поля поиска переходит в список, `↑`/`↓` — по элементам, `Enter` — как `+`.
- **Пустой поиск:** `Nothing found. Try another word or open Apps` / `Ничего не найдено. Попробуйте другое слово или вкладку «Программы»`.
- **Общее правило окна:** ни одна кнопка, вкладка или подпись не должна вылезать за край при русском языке и минимальной ширине окна. Все ряды кнопок — `min-width: 0` и многоточие, или перенос, а не `nowrap` с обрезкой.

### 4.13 Телефон: нет связи с ПК — выход есть всегда (отзыв владельца 2026-11-24: «если телефон не может подключиться, он не может заново войти»)
- **Фон:** телефон сам переподключается — сразу, затем через 1, 2, 5, 10 с и дальше каждые 10 с; немедленно — при возврате приложения на экран (`visibilitychange`) и при `online`.
- **Карточка поверх затемнённой раскладки** — через 8 с без связи (или сразу, если ПК отверг ключ):
  - заголовок `Can't reach {pc}` / `Нет связи с {pc}`; под ним причина: ПК не отвечает → `The PC doesn't answer` / `ПК не отвечает`; ПК отверг ключ (auth/hello2 отклонены, устройство забыто, ключи сменились) → `This PC doesn't know this phone anymore` / `ПК больше не знает этот телефон` — тогда фоновые попытки прекращаются;
  - кнопки: `Try again` / `Повторить` (основная; при отказе ключа её нет) · `Connect again` / `Подключить заново` (открывает экран первого подключения: сканер QR и ввод кода; сохранённый ПК не удаляется, пока новое подключение не удалось) · мелкой ссылкой `Use another PC` / `Другой ПК`;
  - подсказки свёрнуто (`Why?` / `Почему?`): телефон и ПК в одной сети Wi-Fi; Decka запущена на ПК; если сеть на ПК отмечена как общественная — Decka в ней телефоны не принимает (ARCHITECTURE, политика сетей), сделайте её частной или разрешите в настройках Decka; по USB — проверьте кабель.
  - пока карточка видна, попытки продолжаются; при успехе карточка исчезает сама.
- **Всегда доступно, даже без связи:** `More → Connect again` / `Подключить заново` и `Use another PC`. Ни один путь к первому подключению не требует связи с ПК.
- **QR со сменившимся адресом:** повторное сканирование QR того же ПК обновляет адрес и ключ сохранённой записи, а не создаёт вторую.

### 4.12 Голос: плашка на ПК и кнопка на телефоне (M21, DATA_MODEL.md §12.6)

### 4.11 Виджет лимитов ИИ — меньше текста (отзыв владельца 2026-11-21)

Владелец: «информативно, но много текста, некрасиво». Принцип: **цифра и форма вместо слов**. Подробности — по тапу.

- **Знаки провайдеров:** Claude — `si:claude` из simple-icons (уже в сборке, T14.13), цвет `#D97757`. Codex — Phosphor `terminal-window`, цвет `onSurface` текущей темы (логотипа OpenAI в simple-icons нет — не рисовать свой).
- **Цвет уровня** для колец и полос: < 70% — акцент, 70–89% — `warning`, ≥ 90% — `error`.
- **Время до сброса** — символ `↻` и самое короткое значение: `↻ 2ч 14м` (≥ 1 сут — `↻ 3д`, < 1 ч — `↻ 14м`). Слов «resets in» / «сброс через» нет.
- **Прогноз** — только когда лимит кончится раньше сброса: значок `warning` и время `⚠ 14:20` вместо `↻`. Строки «Runs out…» нет.
- **По размерам** (`show: "both"`; при одном провайдере он занимает всё место):
  - **2×1:** два кольца рядом (по одному на провайдера). Кольцо — 5-часовое окно Claude / первичное окно Codex, толщина 4 px. Внутри кольца — процент (15 px, вес 600). Под кольцом — знак провайдера 12 px. Больше ничего.
  - **2×2:** кольца крупнее, концентрические: внешнее — короткое окно, внутреннее — недельное (7д) или вторичное; толщина 6 px, зазор 3 px. В центре — процент окна, которое ближе к пределу. Под кольцом — знак и `↻` этого окна.
  - **3×2, 4×2:** по строке на провайдера: знак 18 px; две тонкие полосы (6 px, радиус 3 px) с подписями `5ч` / `7д` мелко слева и процентом справа (13 px, `tabular-nums`). Под полосами одна строка `↻` или `⚠` для окна, которое ближе к пределу.
  - **4×2:** справа — сессии Claude (проект, `ctx 34%`), до 3 строк.
- **Нет данных:** знак провайдера приглушённо и `—`. Подсказка о настройке — только при ≥ 3×2, одной строкой, и только для Claude.
- **Ожидающие разрешения:** бейдж-число в углу виджета (как сейчас).
- **Тап по виджету** → лист подробностей (как лист разрешений, DESIGN §4.10):
  - точные проценты и время сброса каждого окна;
  - прогноз;
  - план Codex;
  - время обновления данных;
  - сессии.
  Всё, что раньше было текстом в виджете, живёт здесь.
- **Текст в виджете** — не мельче 11 px. Если не помещается, убирается целиком, без многоточий: сначала подписи окон, потом `↻`.

### 4.8 Библиотека готовых кнопок и наборы (M15, D-46)

- **Левая панель редактора** `Deck` становится библиотекой (заменяет палитру `Apps / Actions / Widgets`): поле поиска сверху (ищет по именам на обоих языках и по категориям), под ним вкладки `Library` / `Sets` / `Apps`.
  - `Library` — список категорий (DATA_MODEL.md §9) с иконкой и стрелкой раскрытия, внутри — пункты строкой: иконка, имя, справа серым — что делает (`Win+Shift+S`, `OBS`). Первая категория раскрыта, остальные свёрнуты; состояние запоминается в `localStorage` окна.
  - `Sets` — карточки наборов: название, описание в одну строку, мини-превью формы (клавиши 14 px) и кнопка `Add`. `requires` не выполнено → вместо `Add` — `Set up OBS` / `Set up weather` (ведёт в настройку).
  - `Apps` — установленные программы, как раньше.
- **Как добавить:** перетащить пункт на клетку превью (pointer-события, D-38) **или** двойной клик — в первую свободную клетку текущей страницы, **или** выделить пустую клетку и нажать `Enter` на пункте. Набор — `Add` или перетаскивание карточки (тень формы показывает, куда ляжет; не помещается — подсказка `Will go to a new page "<name>"`).
- **Пункты с `ask`**: после броска — маленький диалог у клетки: `url` — поле адреса; `keys` — запись сочетания; `obs_scene` / `obs_input` — список из `obs_status()` (OBS не подключён → `Connect OBS first` и ссылка на настройки); `page` — список страниц.
- **Редактор цепочки** (`Sequence`): диалог со списком шагов: шаг = выбор из `Your actions` или `Wait` (поле мс, по умолчанию 500); перетаскивание для порядка, `+ Add step`, удаление крестиком; снизу итог `5 steps · 1.5 s`. Имя цепочки — поле сверху. Ограничения DATA_MODEL.md §2.3 показываются у шага сразу.
- **Быстрый выбор** (§4.5) показывает те же категории в том же порядке; `Media & system` заменяется категориями каталога.
- **Мастер первого запуска**, шаг 3: над списком программ — строка карточек наборов с флажками (`Media remote` и `Sound` отмечены по умолчанию, `Streaming` — только если OBS найден: процесс `obs64.exe` запущен или OBS установлен по ярлыку); выбранные вставляются `insertSet`.

### 4.16 Телефон: единый язык виджетов и экранов (решение владельца 2026-11-25: «как новое окно ПК»; ориентиры — виджеты iOS/Android 14, Nothing OS; только идеи). Темы §1 и геометрия §2 не меняются — меняется содержимое виджетов, листы и служебные экраны
- **Шапка виджета** (у всех виджетов с `h ≥ 2` или `w ≥ 3`): строка сверху — иконка 14 px + имя 12 px / 600 прописными с разрядкой 0.04em, цвет текста темы 60 %. У `1×1` и `2×1` шапки нет.
- **Плотность по размеру** — через `container queries` (`container-type: size` на панели виджета), не через JS: у каждого виджета описаны вида `S` (≤ 2 клеток), `M` (3–4), `L` (≥ 6). Место под текст песен (M24) не резервировать.
- **Таймер / часы:** цифры главного размера; кольцо прогресса таймера 4 px акцентом; пресеты — «пилюли» высота 28.

- **Пустое состояние любого виджета** (нет данных, сервис не настроен): иконка виджета 24 px 40 % + одна строка 12 px `Not set up` / `Не настроено` или `No data` / `Нет данных`. Никаких «—» в пустых кольцах и графиках.

**M19 (решение владельца 2026-11-20, D-51): 11 языков.**

| Код | Язык | Название в списке |
|---|---|---|
| `en` | английский (исходный) | English |
| `zh` | китайский (упрощённое письмо) | 中文（简体） |
| `hi` | хинди | हिन्दी |
| `es` | испанский | Español |
| `ar` | арабский (письмо справа налево) | العربية |
| `fr` | французский | Français |
| `pt` | португальский (бразильский) | Português (Brasil) |
| `ru` | русский | Русский |
| `de` | немецкий | Deutsch |
| `ja` | японский | 日本語 |
| `kk` | казахский (кириллица) | Қазақша |

- **Порядок в списке выбора:** `Auto (system)`, затем по названию на самом языке; `English` и язык системы — первыми.
- **`auto`:** берётся первая часть `navigator.language` (`zh-TW` → `zh`, `pt-PT` → `pt`). Языка нет в таблице → `en`. Трей определяет язык по `GetUserDefaultUILanguage()`: `0x19` ru, `0x3F` kk, `0x0A` es, `0x04` zh, `0x39` hi, `0x01` ar, `0x0C` fr, `0x16` pt, `0x07` de, `0x11` ja.
- **Словари:** `shared/src/i18n/<код>.ts`, тип `Record<keyof typeof en, string>`: пропущенный ключ — ошибка компиляции.
- **Множественное число:** `Intl.PluralRules(<код>)`. `t()` ищет `key.<категория>`, затем `key.other`, затем `key.one`. Дополнительные формы (`zero`, `two`, `few`, `many` — нужны для `ar`, `ru`, `kk`) — необязательные ключи сверх `en`.
- **Глоссарий** всех языков — `shared/src/i18n/GLOSSARY.md`. Это таблица терминов из глоссария ниже (Deck, Phone, key, page, popup group, widget, action, Pair…) по каждому языку. Пишется до перевода и обязателен для всех словарей.
- **Арабский — справа налево:** окно настроек, меню и листы телефона, тосты, мастер получают `dir="rtl"`. В CSS вместо `left`/`right`, `margin-left` и т. п. — логические свойства (`inset-inline-start`, `margin-inline-start`, `text-align: start`). Сетка кнопок, страницы и свайп остаются `dir="ltr"`: координаты клавиш — данные пользователя. Внутри клавиш и виджетов `dir="auto"`. Стрелки «назад/вперёд» в меню отражаются.
- **Шрифты:** системные (`system-ui`, на Windows для хинди — Nirmala UI, для китайского и японского — Microsoft YaHei / Yu Gothic, на Android — Noto). Свои шрифты не подключаются.
- **Длина:** немецкий длиннее английского на 30–40%, хинди и казахский — тоже. Действует правило §4.8a: ничто не обрезается без многоточия и `title`.
- **Качество:** переводы делает модель по глоссарию. В README раздел `Translations`: как прислать исправление. Носителями проверены только `ru` и `kk` (владелец).

Языки до M19: английский (`en`, исходный) и русский (`ru`). Переводится всё, что видит пользователь: телефон, окно настроек, меню трея, системные уведомления агента. Не переводятся: данные пользователя (подписи кнопок, имена страниц, тексты уведомлений из API), имена программ, сообщения в логах.

- **Настройка:** `display.language` (DATA_MODEL.md §3): `"auto"` (по умолчанию) | `"en"` | `"ru"`. Задаётся в окне настроек (`More → Settings → Language`: `Auto (system)` / `English` / `Русский`; название каждого языка — на нём самом) и на первом шаге мастера (переключатель в правом верхнем углу). Применяется сразу, без перезапуска; телефон получает её с секцией `layout`.
- **`auto`:** каждое устройство берёт свой системный язык: окно — `navigator.language` WebView2, телефон — `navigator.language` WebView, трей — `GetUserDefaultUILanguage()` (основной язык `0x19` → `ru`). Начинается с `ru` → русский, иначе английский. До сопряжения телефон всегда работает как `auto`.
- **Механизм:** собственный модуль без зависимостей `shared/src/i18n/` — `en.ts` (ключ → строка, источник истины), `ru.ts` с типом `Record<keyof typeof en, string>` (пропущенный ключ — ошибка компиляции), `t(key, params?)` с подстановкой `{name}`, множественное число через `Intl.PluralRules` (`ru`: `one` / `few` / `many`; ключи вида `keys_count.one`). Даты и время — `Intl` с выбранным языком (часы на телефоне уже так работают).
- **Ошибки:** телефон показывает свои тексты по `code` (PROTOCOL.md §5) — переводятся. Замечания проверки, которые присылает агент (`ValidationIssue.message`) и тексты `press_result.error`, остаются английскими в этой версии; окно показывает их как есть.
- **Длина:** русский текст в среднем на 20–30% длиннее.
