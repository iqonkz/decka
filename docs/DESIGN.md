# DESIGN.md — визуальная система Decka (M13)

Решение владельца 2026-11-15: визуальная часть — главный приоритет продукта. Этот документ — единственный источник значений для тем, геометрии, анимаций и UX-потоков. Исполнитель не подбирает цвета и размеры на глаз: всё, чего здесь нет, — запись в `BLOCKERS.md`.

Правила для всех тем:
- Чужие фирменные ресурсы NEVER: никаких логотипов, иконок, шрифтов и названий Elgato, Apple, Google в интерфейсе. Темы — собственные интерпретации стилей.
- Одна геометрия для всех тем (§2): тема меняет только поверхности, цвета, тени, эффекты и анимации нажатия. Раскладка от смены темы не меняется.
- Защита AMOLED (M8) действует во всех темах: затемнение, заставка, pixel shift.
- Контраст подписей ≥ 4.5:1 к фону клавиши (WCAG AA) во всех темах; проверяется в T13.11.

## 1. Темы

`display.theme`: `"amoled" | "studio" | "material" | "glass"`. По умолчанию для новых установок — `"studio"`; отсутствие поля в существующем `layout.json` = `"amoled"` (у пользователя ничего не меняется без его выбора).

Темы реализуются как наборы CSS-переменных на корне клиента (`[data-theme="…"]`) плюс модификаторы компонентов. Названия в окне настроек: `AMOLED`, `Studio`, `Material`, `Glass`.

### 1.1 AMOLED — «чёрный экран, тонкая обводка»

| Токен | Значение |
|---|---|
| фон экрана | `#000000` |
| лицевая сторона клавиши | прозрачная |
| обводка | `1px solid rgba(255,255,255,0.16)`; цветная клавиша — `color` с непрозрачностью 0.5 |
| цветная клавиша | фон `color` с непрозрачностью 0.16, иконка `color` (тёмные цвета, яркость < 64 — иконка `#e5e5e5`) |
| иконка / подпись | `#e5e5e5` / `#9ca3af`, вес 500 |
| радиус | `0.22 × side` |
| тень, блик | нет |
| нажатие | фон `rgba(255,255,255,0.10)`, масштаб 0.94 |
| панели виджетов | без фона и обводки |

### 1.2 Studio — «аппаратная дека»

| Токен | Значение |
|---|---|
| фон экрана | `#000000` |
| лицевая сторона | `linear-gradient(180deg, #1c1c22, #0d0d10)` |
| цветная клавиша | `linear-gradient(180deg, mix(color, white 12%), mix(color, black 18%))`, иконка `#ffffff` |
| обводка | `1px solid rgba(255,255,255,0.10)` (цветная — 0.18) |
| блик / тень | `inset 0 1px 0 rgba(255,255,255,0.08)` / `0 2px 6px rgba(0,0,0,0.7)` |
| иконка / подпись | `#f2f2f2` / `#ffffff`, вес 600, `text-shadow: 0 1px 2px rgba(0,0,0,0.9)` |
| радиус | `0.16 × side` |
| нажатие | масштаб 0.94, тень `inset 0 2px 6px rgba(0,0,0,0.8)`, `brightness(1.25)` |
| панели виджетов | та же лицевая сторона без цвета |

### 1.3 Material — по мотивам Material 3 (тёмная схема)

- Палитра генерируется из акцентного цвета `display.accent` (по умолчанию `#7c5cff`) библиотекой `@material/material-color-utilities` 0.4.0: `SchemeTonalSpot` (или эквивалент API этой версии), `isDark = true`, contrast 0. Используются роли: `surface`, `surfaceContainer`, `surfaceContainerHigh`, `onSurface`, `onSurfaceVariant`, `primary`, `primaryContainer`, `onPrimaryContainer`, `outlineVariant`.
- Фон экрана: `surface`. Клавиша: `surfaceContainerHigh`, иконка `onSurface`, подпись `onSurfaceVariant`, вес 500. Обводки и тени нет (тональная глубина вместо теней).
- Цветная клавиша: для её `color` генерируется своя схема (тот же алгоритм, seed = `color`, кэш по цвету); фон `primaryContainer`, иконка и подпись `onPrimaryContainer`.
- Радиус: `0.24 × side`; при нажатии радиус анимируется до `0.36 × side` (морфинг формы) и поверх — слой состояния `onSurface` с непрозрачностью 0.12; отпускание — обратно за 150 мс.
- Пульсация состояния `pending` — кольцо цвета `primary`.
- Панели виджетов: `surfaceContainer`, радиус `0.24 × side`.
- Шрифт: системный (`system-ui`; на Android это Roboto).

### 1.4 Glass — «жидкое стекло»

Цель — максимально близкое к системному стеклу Apple ощущение средствами WebView: размытие и насыщение фона, преломление по краям, зеркальный блик на кромке, лёгкая «упругость» при нажатии. Это интерпретация, не копия: системный материал Apple в WebView недоступен.

- Фон (обязателен — стеклу нужно что-то за собой): `display.wallpaper` (§1.5), по умолчанию `"aurora"`.
- Клавиша (слои снизу вверх):
  1. `backdrop-filter: blur(16px) saturate(180%)` + фон `rgba(255,255,255,0.07)`;
  2. преломление: SVG-фильтр `#decka-glass` (`feTurbulence` baseFrequency 0.008, numOctaves 2 → `feGaussianBlur` 2 → `feDisplacementMap` scale 26, каналы R/G), применённый как `backdrop-filter: url(#decka-glass) blur(16px) saturate(180%)` — **только если поддерживается** (проверка в T13.5); иначе слой пропускается;
  3. кромка: псевдоэлемент с рамкой 1px и маской-градиентом `linear-gradient(135deg, rgba(255,255,255,0.55), rgba(255,255,255,0.08) 40%, rgba(255,255,255,0.0) 60%, rgba(255,255,255,0.25))`;
  4. внутренний блик: `inset 0 1px 1px rgba(255,255,255,0.45), inset 0 -1px 1px rgba(255,255,255,0.08)`;
  5. тень: `0 6px 18px rgba(0,0,0,0.35)`.
- Цветная клавиша: дополнительный слой `color` с непрозрачностью 0.32 под бликом.
- Иконка `#ffffff` с `drop-shadow(0 1px 2px rgba(0,0,0,0.35))`; подпись `#ffffff`, вес 600, та же тень.
- Радиус `0.26 × side`.
- Нажатие: масштаб 0.92 с «пружиной» (`cubic-bezier(0.34, 1.56, 0.64, 1)`, 260 мс на отпускание), блик ярче (`inset 0 1px 2px rgba(255,255,255,0.75)`), световое пятно из точки касания (радиальный градиент `rgba(255,255,255,0.25)`, гаснет за 300 мс).
- Панели виджетов — то же стекло, радиус `0.26 × side`.
- Производительность: при старте темы клиент 3 с меряет частоту кадров (`requestAnimationFrame`); средняя < 45 к/с → режим `reduced` (без слоя 2, `blur(10px)`), сохраняется в `localStorage` ключом `decka.glass.reduced.v1`. Переключатель `Reduce effects` в меню телефона (§4.3) принудительно включает/выключает режим.

## 2. Геометрия (общая)

Функция `gridMetrics(viewport, cols, rows)` — как в TASKS.md T11.10 «Итоговая спецификация» п. 1: квадратные клавиши со стороной `side`, зазор `max(4, round(0.04 × side0))`, сетка центрирована.

| Элемент | Значение |
|---|---|
| иконка `lucide:`/`emoji:`/`img:` svg | `round(0.46 × side)`; со смещением вверх `0.07 × side`, если есть подпись |
| иконка `img:` png | `round(0.62 × side)`, скругление `0.10 × side`; при наличии подписи — `0.52 × side` |
| подпись | внутри клавиши снизу, отступ `0.07 × side`, `max(11px, 0.14 × side)`, одна строка с многоточием; без иконки — по центру, `0.19 × side`, до двух строк |
| шеврон `navigate` | `›` в правом верхнем углу, `0.14 × side`, непрозрачность 0.5 |
| значок `popup` | три точки `•••` в правом верхнем углу, `0.12 × side`, непрозрачность 0.5 |
| панель виджета | внутренний отступ `0.08 × side` |

## 3. Движение

| Событие | Анимация |
|---|---|
| смена страницы свайпом | страница следует за пальцем; отпускание — доводка за 220 мс `cubic-bezier(0.2, 0.8, 0.2, 1)`; порог — 25% ширины или скорость > 0.5 px/мс |
| смена страницы кнопкой / контекстом | сдвиг 220 мс в сторону направления |
| нажатие клавиши | по теме (§1); вход 80 мс, выход 150 мс (Glass — пружина 260 мс) |
| открытие всплывающей группы (§4.1) | затемнение фона 160 мс; панель из точки нажатой клавиши: `scale 0.85 → 1`, `opacity 0 → 1`, 200 мс, пружина; закрытие — обратное, 140 мс |
| тост | сверху: `translateY(-8px) → 0`, `opacity`, 180 мс |
| `prefers-reduced-motion` или режим `reduced` | все переходы ≤ 100 мс без масштабирования, пружины заменяются на `ease-out` |

## 3a. Виброотклик (решение владельца 2026-11-15)

Реализация: в приложении — `@capacitor/haptics` 8.0.2; в браузере — `navigator.vibrate(ms)` (где есть; в незащищённом контексте и на iOS-браузерах отсутствует — молча пропускать). Все вызовы — через один модуль `client/src/platform/haptics.ts` (`haptic(kind)`), ошибки глотаются.

| Событие | `kind` | Capacitor | Браузер (`vibrate`) |
|---|---|---|---|
| касание клавиши (`pointerdown` на кнопке, ключе виджета, клавише панели группы) | `tap` | `impact({ style: Light })` | 10 мс |
| завершение удержания `confirm` (800 мс) — в момент отправки | `confirm` | `impact({ style: Medium })` | 20 мс |
| ответ `press_result` с ошибкой (или таймаут) | `error` | `notification({ type: Error })` | `[30, 60, 30]` |
| открытие всплывающей группы | `open` | `impact({ style: Light })` | 10 мс |
| смена страницы (свайп, кнопка, контекст) | `page` | `selectionChanged()` (между `selectionStart`/`selectionEnd`) | 5 мс |
| долгое нажатие открыло меню телефона | `menu` | `impact({ style: Medium })` | 20 мс |

- Успешный `press_result` вибрацией не сопровождается (касание уже дало отклик; двойной отклик раздражает).
- Касание, которое только будит экран из `dim`/`sleep`, не вибрирует.
- Контекстная смена страницы, произошедшая без участия пользователя, не вибрирует (только ручная).
- Настройка на устройстве: переключатель `Haptics` в меню телефона (§4.3), по умолчанию включён; хранится в `localStorage` ключом `decka.haptics.v1` (try/catch). Глобальной настройки на ПК нет: это свойство конкретного телефона.
- Чистая функция `hapticFor(event, ctx) → kind | null` (учитывает правила выше и настройку) — с юнит-тестами.

## 4. UX-потоки

### 4.1 Всплывающие группы — релевантные кнопки по нажатию

Нажатие клавиши показывает поверх текущей страницы панель связанных кнопок (как раскрывающиеся группы на сенсорной панели ноутбука и папки на аппаратных деках).

- Источник кнопок — страница с `popup: true` (DATA_MODEL.md §3.1). Такие страницы не участвуют в свайпе, не показываются точками, не могут иметь `apps` и не могут быть первой страницей.
- Кнопка с `popup: <pageId>` открывает панель. Вариант «запустить и показать»: `actionId` + `popup` — сначала `press(actionId)`, после `ok` открывается панель (например, «VS Code»: запустить/активировать и сразу показать его команды). При ошибке действия панель не открывается.
- Панель: элементы popup-страницы раскладываются по своей ограничивающей рамке (`min x…max x+w`, `min y…max y+h`) с той же `side` и зазором; поверхность панели — панель виджета текущей темы с отступом `0.12 × side`; позиция — по центру над нажатой клавишей, сдвинута так, чтобы целиком помещаться на экране с отступом `pad`.
- Фон под панелью затемняется `rgba(0,0,0,0.55)` (Glass — плюс `backdrop-filter: blur(6px)`).
- Закрытие: тап вне панели; через 250 мс после успешного нажатия кнопки внутри панели, если у popup-страницы не задано `stayOpen: true`; через 10 с без касаний; жестом свайпа вниз по панели.
- Вложенность запрещена: кнопка с `popup` на popup-странице — ошибка валидации.

### 4.2 Контекстные страницы (M11) и группы вместе

Контекстная страница (по активному приложению) меняет всю страницу; группа — временная панель по нажатию. Открытая группа закрывается при автоматической смене страницы.

### 4.3 Меню телефона

Долгое нажатие 1,2 с на пустом месте страницы или на точках страниц (с круговым индикатором удержания) открывает нижний лист:
- строка состояния: `Connected to <PC> · USB` / `· Wi-Fi` / `Offline`;
- `Reduce effects` (переключатель, влияет на Glass и анимации);
- `Haptics` (переключатель виброотклика, §3a);
- `Reload`;
- `Unpair` (с подтверждением);
- версия приложения.
Скрытый жест «5 тапов в углу» удаляется (заменён меню).

### 4.4 Окно настроек

- **Мастер первого запуска** (если `devices.json` пуст и раскладка не менялась): 1) `Pair your phone` — крупный QR и код; 2) `Pick a look` — четыре карточки тем с живым превью; 3) `Add your apps` — список установленных программ (M12) с флажками: выбранные становятся действиями и кнопками на первой странице в свободных клетках; кнопки `Back` / `Next` / `Skip`.
- **Редактор раскладки «что видишь — то и получишь»**: в центре — настоящий рендер деки в выбранной теме (общие компоненты `@decka/ui`, DECISIONS.md D-37) в рамке условного телефона в альбомной ориентации; клик по клавише — панель свойств справа; перетаскивание клавиши — перемещение на пустую клетку или обмен с занятой; перетаскивание из левой палитры (вкладки `Apps`, `Actions`, `Widgets`) на клетку — создание; угловая ручка у виджета — изменение размера; `Ctrl+Z`/`Ctrl+Y` — отмена/повтор (50 шагов); `Ctrl+S` — сохранить; метка `Unsaved changes`.
- **Вкладка `Appearance`**: тема (4 карточки с превью), акцент (для Material; 8 готовых цветов + произвольный), обои (для Glass), переключатель контекстных страниц, параметры экрана (перенос блока `Display` из Layout).
- Внешний вид окна: системный шрифт `Segoe UI Variable` / `system-ui`; сетка отступов 8 px; боковое меню с иконками Phosphor (regular, 20 px); светлая и тёмная тема окна по системной; акцент окна = `display.accent`.

## 5. Иконки

- Встроенный быстрый набор — 60 иконок Lucide (DATA_MODEL.md §3.6) — остаётся в клиенте.
- Библиотека для выбора в окне настроек — **Phosphor Icons** (`@phosphor-icons/core` 2.1.1, MIT): все иконки во всех начертаниях (`thin`, `light`, `regular`, `bold`, `fill`, `duotone`). Пакет входит только в окно настроек; в клиент не попадает.
- Выбор иконки Phosphor → SVG передаётся в агент `icon_from_svg` → хранится как `img:<hash>` (DATA_MODEL.md §8.4) → на телефоне рисуется маской (`mask-image`) цвета иконки текущей темы, поэтому подстраивается под тему и цвет клавиши.
- Иконки программ (M12) — PNG, рисуются как есть, без перекраски.
- Средство выбора иконки (`IconField`, T12.5) получает вкладки: `Phosphor` (поиск по имени и тегам, переключатель начертания, сетка с виртуализацией), `Quick` (Lucide), `Program`, `Image`, `Emoji`.
