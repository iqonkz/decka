# MANUAL_CHECKS.md — ручные проверки для владельца

Формат: задача, текст пункта, статус. `PENDING (owner)` — нужен человек с экраном или телефоном.
Автоматически подтверждено исполнителем (headless Chrome, `--dump-dom`) отмечено отдельно.

## T4.3 — экран сопряжения

- PENDING (owner): открыть `http://127.0.0.1:19247/#c=TESTCDE2&h=127.0.0.1&p=19247&n=Test` в обычном браузере и убедиться, что `#c=...` пропал из адресной строки (`history.replaceState`). DOM-дамп адресную строку не показывает.
- DONE (автоматически, Chrome headless): после открытия URL виден `Connected to <имя ПК>`; после повторного открытия `http://127.0.0.1:19247/` с тем же профилем надпись остаётся (токен сохранён, в `devices.json` одно устройство); на чистом профиле показан экран `Pair with your PC`.

## T4.4 — сетка, страницы, свайп

- DONE (автоматически, Chrome headless): с конфигом по умолчанию на первой странице 10 плиток, точек две.
- PENDING (owner): свайп влево (≥ 60 px по горизонтали, < 40 px по вертикали) открывает страницу `Dev` с 5 плитками; плитка `Main` на ней возвращает на первую страницу; плитки стоят в позициях из `layout.default.json`. Жесты в headless-дампе проверить нельзя.
